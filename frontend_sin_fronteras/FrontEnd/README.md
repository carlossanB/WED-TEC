# 🌐 Sin Fronteras - FrontEnd

Este directorio contiene el código fuente de la aplicación web y landing page de **Sin Fronteras**.

Para la documentación completa, análisis general y arquitectura del proyecto, consulta el archivo principal en la raíz: [README.md](../README.md).

---

## 🚀 Inicio Rápido

### Requisitos
- **Node.js** >= 20.x (Recomendado Node 22)
- **pnpm** >= 9.x o `npm`

### Instalación y Ejecución

```bash
# 1. Instalar dependencias
pnpm install
# (o: npm install)

# 2. Iniciar en modo desarrollo
pnpm dev
# (o: npm run dev)
```

La aplicación se abrirá en `http://localhost:5173`.

### Scripts Disponibles
- `pnpm dev`: Inicia el servidor de desarrollo Vite con Hot Reload.
- `pnpm build`: Genera la compilación optimizada en la carpeta `dist/`.
- `pnpm preview`: Previsualiza el bundle de producción localmente.
- `pnpm format`: Formatea el código con `oxfmt`.
